# Crux

Crux is a discontinued Discord bot project featuring moderation, automation, AI-powered utilities, ticket systems, community tools, and various server management features.

The codebase was written with the assistance of multiple AI coding agents, but building and maintaining the project still required a significant amount of time, iteration, testing, debugging, and problem-solving. Development involved countless bugs, broken features, failed experiments, architectural changes, and more frustration than originally expected.

This project taught me a lot, but it also became increasingly difficult and exhausting to maintain. After spending a considerable amount of time resolving issues only to encounter new ones, I decided to discontinue active development.

The source code is now publicly available for anyone who wants to study it, fork it, improve it, or continue its development. Be warned: the project is incomplete, contains known and unknown issues, and will likely require patience to work with.

If someone decides to continue this project or build something better from it, I hope the time, effort, frustration, and lessons that went into Crux can at least become useful to someone else.

This repository is no longer actively maintained.
